## Что умеет

Чат-органайзер. Пишешь сообщения, прикрепляешь файлы, делишься геолокацией. Всё синхронизируется между вкладками через WebSocket. История хранится на сервере в памяти (после перезапуска бэкенда пропадает — так и задумано).

### Текстовые сообщения

Вводишь текст в поле внизу, жмёшь Enter или кнопку «Отправить». Сообщение появляется справа. Ссылки вида `https://example.com` автоматически становятся кликабельными — открываются в новой вкладке.

### Файлы

Два способа отправить:
- нажать на 📎 слева от поля ввода и выбрать файл;
- перетащить файл прямо в область сообщений (drag & drop).

Картинки показываются как `<img>`, видео — с плеером, аудио — с плеером. Остальные файлы (архивы, документы) — строкой «имя_файла Скачать», где «Скачать» — ссылка.

### Геолокация

Нажимаешь 📍 — браузер спрашивает разрешение. После подтверждения отправляются координаты. В чате появляется ссылка на OpenStreetMap с меткой.

### Смайлики

Два способа:
- набрать код вручную: `:smile:`, `:fire:`, `:heart:` и т. д. При отображении превращается в emoji;
- нажать 😀 и выбрать из панели — вставится в позицию курсора.

### Поиск

Поле вверху справа. Вводишь запрос — через 300 мс отправляется на сервер. Ищет по тексту сообщений и по именам файлов. Результаты подсвечиваются жёлтым. Очищаешь поле — возвращается обычный список.

### Закрепление

Наводишь мышь на сообщение — появляется 📌. Нажимаешь — сообщение закрепляется, показывается в блоке сверху. Одновременно можно закрепить только одно. Нажатие 📌 на другом сообщении открепляет предыдущее. Крестик в закреплённом блоке — открепить совсем. Синхронизируется между вкладками.

### Подгрузка сообщений

Сначала грузятся последние 10. Когда прокручиваешь контейнер наверх — подгружаются ещё 10. И так до начала истории.

## Технологии

- **Frontend:** Webpack, Babel, ESLint, чистый JS (без фреймворков)
- **Backend:** Koa, WebSocket (`ws`), хранение в памяти, файлы в папке `files/`
- **Деплой:** фронт на GitHub Pages через GitHub Actions, бэк на Render
