# Chat

[![Node.js CI](https://github.com/DanBrwn12/ahj_diplom/actions/workflows/node.js.yml/badge.svg)](https://github.com/DanBrwn12/ahj_diplom/actions/workflows/node.js.yml)

[Ссылка на GitHub Pages](https://danbrwn12.github.io/ahj_diplom/)

Бэкенд развёрнут на Render: https://ahj-diplom.onrender.com

## Функции

### Обязательные
- Сохранение текстовых сообщений и ссылок
- Ссылки кликабельны
- Сохранение файлов (картинки, видео, аудио) через Drag & Drop и иконку загрузки
- Скачивание файлов
- Ленивая подгрузка сообщений (по 10)

### Дополнительные
- Синхронизация между окнами через WebSocket
- Поиск по сообщениям
- Отправка геолокации
- Смайлики (коды `:smile:` и панель emoji)
- Закрепление сообщений (pin)
